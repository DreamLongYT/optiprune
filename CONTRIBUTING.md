# Contributing to Optiprune

We welcome contributions to Optiprune! By participating in this project, you agree to abide by our code of conduct.

## How to Contribute

1.  **Fork the repository:** Start by forking the Optiprune repository to your GitHub account.
2.  **Clone your fork:** Clone the forked repository to your local machine:

    ```bash
    git clone https://github.com/DreamLongYT/optiprune.git
    cd optiprune
    ```

3.  **Install dependencies:** Install the project dependencies:

    ```bash
    pnpm install
    ```

4.  **Create a new branch:** Create a new branch for your feature or bug fix:

    ```bash
    git checkout -b feature/your-feature-name
    ```

5.  **Make your changes:** Implement your changes, ensuring they adhere to the project's coding style and conventions.

6.  **Run tests:** Before submitting, make sure all existing tests pass and add new tests for your changes:

    ```bash
    pnpm test
    ```

7.  **Commit your changes:** Write clear and concise commit messages.

    ```bash
    git commit -m "feat: Add new feature X"
    ```

8.  **Push to your fork:** Push your changes to your forked repository:

    ```bash
    git push origin feature/your-feature-name
    ```

9.  **Create a Pull Request:** Open a pull request from your fork to the `main` branch of the original Optiprune repository. Provide a detailed description of your changes.

## Code Style

We use Prettier for code formatting. Please ensure your code is formatted correctly before submitting a pull request.

## Reporting Bugs

If you find a bug, please open an issue on GitHub. Include a clear description of the bug, steps to reproduce it, and any relevant error messages.

## Feature Requests

We welcome feature requests! Please open an issue on GitHub to propose new features or enhancements.
